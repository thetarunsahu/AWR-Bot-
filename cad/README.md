# CAD / Fusion Workspace

This directory will hold documentation and export files related to the Fusion AMR design.

Planned contents:

- chassis design notes,
- modular-interface dimensions,
- attachment design notes,
- mesh exports for simulation,
- STL/STEP exports where appropriate,
- structural simulation results,
- topology/generative optimization evidence,
- manufacturing / 3D-print notes.

The authoritative Fusion cloud design may remain in Autodesk Fusion; exported artifacts placed here should include version/date notes.
