# Hardware Workspace

Physical prototype documentation lives here.

Expected files:

- `BOM.md` — hardware inventory and cost,
- chassis measurements,
- wiring diagrams,
- motor / driver specifications,
- battery and power notes,
- LiDAR / IMU mounting notes,
- emergency-stop design,
- modular attachment build notes,
- physical test results.

Measured values from the physical robot should be fed back into `docs/DECISIONS.md` and the CAD/URDF models.
